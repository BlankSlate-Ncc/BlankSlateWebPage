## How to Use

### 1. **Update Contact Information**

In `index.html`, replace:
- `YOUR_GOOGLE_FORM_LINK` - Add your Google Form embed link for bookings
- `91XXXXXXXXXX` - Replace with your WhatsApp number
- `+91-XXXXXXXXXX` - Add your phone number
- `info@blankslate.com` - Add your email address

### 2. **Add Images**

Upload these image files to your repository:
- **logo.png** - Your Blank Slate logo (will display at 50x50px)
- **art1.jpg** - First gallery artwork
- **art2.jpg** - Second gallery artwork
- **art3.jpg** - Third gallery artwork

### 3. **Enable GitHub Pages**

1. Go to Repository Settings
2. Navigate to Pages section
3. Select "Deploy from a branch"
4. Choose "main" branch and "/" root folder
5. Click Save

Your site will be live at: `https://blankslate-ncc.github.io/BlankSlateWebPage/`

## Customization Guide

### Change Colors
Edit the `:root` color variables in `style.css`:
```css
:root {
  --primary: #FF6B6B;      /* Main red */
  --secondary: #FF8E72;    /* Coral orange */
  --accent: #FFD93D;       /* Golden yellow */
  --dark: #2C3E50;         /* Dark background */
}
```

### Modify Content
- Edit text in `index.html` sections
- Update workshop descriptions in the "Workshops" section
- Add or remove testimonials as needed
- Customize FAQ questions and answers

### Add More Gallery Images
Add more gallery items in the gallery section:
```html
<div class="gallery-item">
  <img src="art4.jpg" alt="Description">
  <div class="gallery-caption">Caption here</div>
</div>
```
